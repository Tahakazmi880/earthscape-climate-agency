## How to run
1. Install Python 3 (or Anaconda).
2. Install the requirement:  pip install -r requirements.txt
3. Start the application:  python app.py
4. Open in a browser:  http://127.0.0.1:5000

## Demo logins
- Administrator:  admin / admin123
- Analyst:        analyst / analyst123

## Pages
- Dashboard: key figures, interpretation, trend and forecast chart, anomaly chart
- Data Explorer: yearly temperature chart for 242 countries
- Predictions: model comparison, test results, future forecasts (2030/2040/2050)
- Alerts: the 41 anomaly alerts generated by the detection model
- Correlation: CO2 vs temperature scatter chart (correlation 0.9655)
- Feedback and Support: submit feedback or an issue (saved for the admin)
- Admin (Administrator only): users and roles, alert threshold, support submissions

## Data
The data files in the data folder are generated from the cleaned project
dataset by prep_data.py (Berkeley Earth, Climate Change: Earth Surface
Temperature Data). All results match the project notebooks and report.
